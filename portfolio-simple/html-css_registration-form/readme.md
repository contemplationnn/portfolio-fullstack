# Registration Form

Небольшой учебный проект — форма регистрации пользователя, выполненная на HTML и CSS.

## Возможности

* Поле логина
* Поле Email
* Поле пароля
* Подтверждение пароля
* Адаптивная форма
* Декоративные элементы с использованием псевдоэлементов `::before` и `::after`
* Эффекты `:hover` и `:active` для кнопки

## Технологии

* HTML5
* CSS3
